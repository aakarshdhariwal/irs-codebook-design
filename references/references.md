# References

Third-party research papers collected during the literature review for this project. All
PDFs are included in this folder for context and convenience; copyright remains with
the original authors and publishers. They are **not** part of the MIT-licensed code in
this repository.

turned out to be a university course's convex-optimization lecture script rather than
third-party research papers, so they were left out of this public copy — see the
project README for details.
